A single-line joke about office life (93 characters, one line) for the
[One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc)
bounty on make.fun.

## The entry

> The coffee machine broke, so now we hold our meetings around the kettle like it's a campfire.

The coffee machine — the one piece of office equipment everyone actually
cares about — breaks, and the team treats the humble kettle like a
campfire, gathering around it for warmth and gossip. The laugh lands on
the last few words: the meeting hasn't moved, only its campfire has.

## How it works

`main.py` is a standard-library-only copier: it copies the finished line
from `entry.txt` into the output directory the grader provides
(`MAKEFUN_OUTPUT_DIR`, default `/output`). Nothing is rendered or
generated at run time, so every run produces the same 93 characters.
